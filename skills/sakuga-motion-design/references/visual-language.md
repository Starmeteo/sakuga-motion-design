# 视觉语言

这里的规则取自固定版本的 Sakuga VFX，给新的对象、主题和场景提供选择依据。**源码事实**指可从源码或原作者文档定位的实现与主张。**素材观察**指直接检查源素材。**设计推断**是从这些证据提炼出的规则。**新增设计**指本 skill 提供的做法。浏览器证据及覆盖范围见 [来源索引](sources.md)。

## 识别这套语言

| 应保留的因果关系 | 源码事实 | 设计推断 |
| --- | --- | --- |
| 安静的常态为动作留出对比 | 原 skill 优先使用原生控件、保留键盘和焦点，静止时不发射。主 Button 有预备、命中和多段余势。 | 先完成静态布局、标签和状态。激活时让对象轮廓变化或短暂反转明暗，随后回到能继续操作的姿态。即使只留一个命中符号，应该仍能看出发生了哪种动作。 |
| 轮廓、亮面、阴影提供三层读形 | `shape()` 描边后在轮廓内裁出阴影与偏移的亮面。烟团 `blob()` 将若干圆作为一个轮廓，内弧标记重叠层。 | 用同方向的硬阴影、少量可辨的特征线和有层次的外轮廓。保留对比与合适线宽，即可更换纸色、墨色、光向和载体。 |
| 力改变形状与方向 | `squashy()` 将竖向压缩与横向扩张绑定。Slider 的宽高、变换原点、数值泡倾角和拖尾都由同一个弹簧速度驱动。 | 同一冲量驱动主体、拖尾与散落方向。力度增加时先加轮廓形变或移动跨度，最后才加粒子。给静态命中区和阅读基线保留稳定位置。 |
| 每种形状讲一个力学角色 | Button 的中心爆形在后层，几何碎片和烟扩散在边缘；Tab 在抵达目标后才产生落点楔和来向短线。 | 把主效果分配给实际接触点、领先沿或方向轴。余势走出中心并缩小、变薄或沿路径被收回。 |
| 语义常驻，装饰短暂 | Checkbox 使用真实 `checked`；Toggle 的 `aria-checked` 与提交值在帧序列之前更新；Progress 有数值和完成文字。 | 视觉轨迹可以滞后，状态应按真实事件交付。读取结果、焦点、理解是否成功以及继续下一步都应有可靠的 UI 通道。 |

## 把时间设计成可认出的姿态

**设计推断。** 用一次实际操作把节拍落在四类事件上。不同动作可以跳过某拍，尤其是键盘直接提交、外部数据同步和轻量撤销。

| 节拍 | 画面决定 | 检查 |
| --- | --- | --- |
| 预备 | 输入已被接住的证据，例如按住变矮、聚焦角标、拖动时沿轴牵引。预备的位置留给真实输入，长按保持可读姿态。 | 按住、从控件拖离后取消，各看一张。取消只走回落或复位。 |
| 命中 | 在提交、释放、穿过阈值或揭示完成的可解释节点给出最强变化。主提示通常由一个轮廓峰值、一个局部特效或一次反转完成。 | 用命中附近两张相邻帧查到峰值，并从实时操作辨认触发和反馈。 |
| 余势 | 主体一次过冲后收回，晚到的烟、碎片、速度线沿动作方向消散。余势的寿命通常长于主体命中峰值，但视觉权重更低。 | 峰值过后的阅读焦点回到文本、目标或状态，尾声不会挡住接下来的操作。 |
| 稳定 | 主体落在最终状态的像素网格或对齐点；几何效果归零，由状态色、边框、文本、勾或位置保留结果。 | 等到效果预算归零再点击。对照静态图测试重复、取消和减少动画状态。 |

**新增设计。** 给各拍写明参考时间和边界。离散反馈可以先试短反差约 33–90 ms、主体恢复约 180–350 ms、余势约 250–650 ms；这些是起调范围。高频列表或编辑界面缩短尾声并删掉大范围效果。场景揭示可以更慢，以实际阅读和场景切换频率复测。针对保持动作，用位置或速度阈值触发命中，别把使用者的手势时长变成固定脚本。

## 形状、伸缩与画面质感

- **新增设计。** 给主体挑一个表力的轴和一处支点。按压以底缘为支点时，顶缘靠近支点，横向略宽。拖拽以运动前沿为支点时，尾侧沿反方向拖长；转向应在速度接近零时回圆，避免同一帧翻转锚点造成跳位。
- **设计推断。** 把面积保持理解为阅读约束。上游 `squashy()` 用 `scaleX = (1 + (1 - y) * wide) * pop`、`scaleY = y * pop`，并未严格面积守恒。Slider 用 `scaleX = st`、`scaleY = 1 / sqrt(st)`，面积比例为 `sqrt(st)`。衍生面板可用 `scaleCross = clamp(scaleAlong ** -exponent, min, max)`，以 `exponent=1` 近似面积守恒，以 `0.5` 获得有意夸张的横拖。长字、脸部或细线图的下限应以实图校准。在子层变形背景与插图，把必要文本放在保形层。 [按压实现](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/core.js#L217-L226) · [Slider 实现](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/slider/slider.js#L58-L68)
- **源码事实 → 设计推断。** 上游单独积分 `x/v/target`，用半隐式欧拉更新，子步不超过 8 ms。 `k` 管恢复推力，`d` 管阻尼，`v` 还能作为效果输入。调快回弹时配合减弱余震，尤其是窄控件；`d/(2√k)` 可作为该单位质量模型的阻尼比对照。离散揭示、划线、贴图可用时间线或逐帧路线，原库的勾描边也使用 CSS 曲线。 [弹簧](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/core.js#L7-L17) · [勾描边](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/checkbox/checkbox.js#L14-L21)
- **新增设计。** 保留填色明暗、描边和局部动作色的职责。将方向性做在轮廓、分面或硬边明暗上。用稳定的随机种子在生成时抖动烟团大小、晶片轮廓或短线长度，单个对象每帧沿一致轨迹变化；每帧重掷取样会把手绘感变成闪烁。小容器优先减小特效密度与重叠、缩短路径。
- **源码事实 → 设计推断。** 上游偏好几何出场。个别路径达到寿命时仍有残留形状，例如 `ring()` 的外轮廓宽度有 2.4 的附加值，`burst()` 的外半径已升到满值；其最后一帧是否突兀要看合成。新绘制以轮廓收至接近零、线宽变薄、头尾相合或局部遮挡收口为宜。 [爆形与环](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/core.js#L108-L132)

## 特效词汇与使用条件

下表把上游绘图函数的形状机制与可迁移用途相连。适用条件属于**设计推断**，取舍和优先级见 [页面与场景](scenes.md)。

| 形状族 | 上游工具与出场方式 | 适用语义与位置 |
| --- | --- | --- |
| 烟团与烟环 | `puff` 滚动、漂移、缩团。`donut` 内孔变大并整体漂移收小。 | 低重力余势、刹停扬尘、擦过地面。锚在后缘或触地边，而烟环适合低优先级的远离中心漂移。 |
| 冲击爆形 | `burst` 有针芒、错位的双星和平涂内外形。 | 有力的提交或终点撞击。主星优先置于主体背后，尖端越过主体轮廓才读得到；为小次要操作用单组楔。 |
| 碎片 | `shards` 选角、翻转、重力曲线和末段缩小，棱面线随小尺寸移除。 | 命中的惯性和材料感，尤其是硬质图形、冲击、越界触底。锥形方向应来自接触法线、运动方向或真实抛出方向。 |
| 斩线 | `slash` 用头先行与尾追赶定义带厚度的弧面；起点用 `ang` 定方向。 | 快速释放、切换手势的余动、掠过后的接续。速度低时只需主体位移或窄线。 |
| 水花 | `splash` 让高低错时的水舌离开基线，液滴沿速度方向拉长并下落。 | 仅在场景有液体、可解释的柔性形变或希望强化黏滞材质时选择。上游 Toggle 水花来自绘制帧，仓库组件的专属实现未调用此 `splash`。 |
| 速度线与楔 | `lines` 顺方向延展、头尾收拢并变细。`ticks` 从半径内缘至外缘扫开小楔，从远端收窄。 | 速度线留在来向区域且与运动平行；楔强调角、锚点或目标，适合轻响应。限制数量和长度，防止盖住标签。 |
| 传导、颤动和闪点 | `ring` 椭圆扩开，`wob` 成对短弧变薄，`kira` 四角星张开与闭合。 | 环适合低强度的发声或触点扩散；颤线标停住或回弹；闪点标识完成或落点的次级强调。 |

## 拟声字

**源码事实。** `don / kachi / shu / pon / zuza / gogo` 是独立轮廓，对应打击、清脆咔嗒、掠过、弹出、滑停、积聚。轮廓由透明 WebP 的像素掩膜追踪成路径，绘制时按词、填充色、边色和网点做 Canvas 缓存。`hollow()`、`dotted()` 固定白色或墨色值，和默认 `P.sfx` 是不同的参数路径。Toggle 的字形直接画在帧里。 [路径追踪](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/tools/trace.py#L10-L33) · [字形绘制](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/core.js#L184-L215)

**素材观察。** 六个字形在轮廓上已有力度差。ドン! 的粗笔带毛边，ポン 更圆，シュッ 倾斜而细长，ゴゴゴゴ 的字块排列带方向。检查原始轮廓比仅凭词义更容易选对力度。

**设计推断。** 拟声字占据显著的注意力。每次反应先给清楚的主体命中，在单次稀有且可容纳的节拍最多选择一个词。裁弱字形可调大小、倾斜、停留、描边和填色。多阶段的任务若有积聚与完成两个词，给它们互斥的时间窗。画面拥挤、高频、减少动画或品牌不需要拟声字时，让主体和形状语言接管。文字的导入、重新描绘和中文素材路线见 [项目风格配置](profiles.md)。

## 允许改变的部分

**新增设计。** 主体可以是文字、图像、指示器、卡片或场景。配色、圆角、字体、描边、冲量、密度和拟声字属于项目设计。摄影图像可保留照片质感，在图像容器、揭示遮罩、取景框或图形特效里表达二色平涂；连续正文可以保持静止，给标题的遮罩边或章标一个命中。若要把长驻波动、透明渐隐、无轮廓的摄影粒子当成主要表达，记录改变了哪条原有画面规则、为什么符合项目、以及替代的读形和退出验收。
