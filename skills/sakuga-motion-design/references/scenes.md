# 页面与场景编排

**新增设计。** 用动作的含义选主体、方向和命中点。做单个控件时可直接使用 [动作规格](motion-recipes.md)；页面或连续手势再使用本页。

## 从动作含义选择反馈

| 动作 | 真正变化 | 锚点与方向 | 默认节拍与效果 |
| --- | --- | --- | --- |
| 拖动 | 预览位置随手更新，提交按项目规则 | 稳定命中面上的抓取点，速度向量作为局部切线 | 慢时主体跟随，快时沿切线拉长，尾迹反向，输出有上限。抬手按意图提交或停下 |
| 落点 | 物件进入明确目标，或回原处 | 对齐目标的接触边，沿入射方向压扁，侧向展开 | 对齐后的压缩占主节拍，少量烟或楔线沿切边散去 |
| 吸附 | 确定对齐归属 | 槽位或导线，指向最近可达锚点 | 越过阈值进入，离开阈值略大以避免抖动，连续经过相邻格时以轮廓为主 |
| 揭示 | 新标题与内容已经可读 | 标题首行、边缘或图像遮罩的开口 | 小幅方向预备，1 次揭示，边缘斩线或轻屑，归位后无图案跨正文 |
| 切换 | 新页/标签/视图成为唯一活动状态 | 共用指标、场景接缝或目标卡 | 用共享标记解释方向，旧效果先被撤销，新标题得到主节拍 |
| 完成 | 业务确认为成功 | 控件背面、进度前沿或目标边 | 单次清晰冲击，随后稳定勾号或文字。慢任务的累计强度受完成节拍约束 |
| 撤销/取消 | 恢复已承诺的状态，或丢弃预览 | 回到原锚点，沿撤退路径 | 低能量收缩或短位移。取消手势清理尾迹和发布队列；若撤销需要确认，保留清晰的文字入口 |

## 新对象规格

- 在**未形变**的命中面和静止布局中标记起止锚点，明确本文用的是视口、页面还是场景容器坐标。DOM 读取锚点 → 转为画布 CSS 像素 → 绘制时统一乘 DPR。图像抓取偏移取指针减对象起点，免去初按跳到中心。
- 把方向转换为切线和法线，正负方向拖动各测一次。短区域可用 px/s 比上对象宽度或轨道长度作归一化。输入采样速度需要时间差下限、上限、低通或峰值衰减；没有新采样时衰减。收手、失焦和取消分别验证，长时间暂停后才松手应安静。
- 按对象大小设形变、半径和最小可读尺度，再剪到场景安全区。体积感用长轴拉伸、短轴补偿，图文只做轻微变形；必要时移动独立边框或装饰层而让正文保持稳定。标题换行、裁切、入口首帧和静止末帧都要验。
- 一个区段标出主动作和容许的次级效果，正文、焦点环、关键数值属于禁遮区。确认态需要文本、原生值或图标的持久组合。可对齐形状交接、错开命中点或抑制次要效果，避免同屏争夺注意力。

## 管理同屏动作

1. **优先级。** 场景提交和显式完成优先，其次为落点和切换，最后是移动尾迹与悬浮。状态都照常提交；当预算满时合并或停发低优先级效果。两主动作靠得很近就替换前一批过期效果，避免用串行排队延误反馈。
2. **强度。** 高频输入用距离/时间阈值、速度门槛和每次手势预算，慢速通过保持安静。键盘步进、单点替代可有局部确认，默认免去依赖连续速度的飞散。布局确认较低频时才给一次完整命中。
3. **层级。** 容器用独立堆叠上下文，背层在主体后，前层仅放小形状和细线。Canvas 设为不可命中且对辅助技术隐藏。先通过场景自身裁切限制溢出，再判断是否需要与页面共享坐标的局部溢出。检查 overflow、滚动容器、sticky、模态窗口、双栏和移动视口边缘。
4. **中断。** 拖动用 pointer capture，处理 pointercancel、lostpointercapture 与窗口失焦。能连续反转的主体从当前姿态和速度重新定向；有明确目的地的揭示动作替换前次任务。定时器、承诺、WAAPI/CSS 动画、粒子应持有本批次标识或取消句柄；移除场景先取消，再释放节点/监听/帧调度。
5. **持续效果。** 进度运行、持续拖动等语义需要时才开启。静止等待与空闲保留可读状态。完成、退出、销毁、隐藏或进入减少动画时，结束或暂停对应层及其后续回调，恢复正常偏好时等待下一次意图。

## 对象移除与恢复

移除若改变布局，先读原位锚点，在同一事件里更新列表及操作结果。余势可画到稳定的操作条或局部独立层；需要保留旧影时用不可命中且不进无障碍树的视觉副本，避免让已移除的控件继续接收输入。恢复先插回真实对象，再以新布局中的原槽位或缩略图边缘作为轻量回落点。

撤销可保留最近一次或一段短历史，按产品预期明示当前会恢复哪个对象。移除后若原焦点失效，按阅读顺序交给相邻操作或稳定的撤销入口；恢复最后一项导致撤销入口不可用时，把焦点交给恢复的对象或列表标题。快速移除和撤销以真实数据的顺序提交，视觉批次只跟随当前动作。读取计数、空状态、撤销可用性和焦点，确认这些信号都在效果结束前可用。
