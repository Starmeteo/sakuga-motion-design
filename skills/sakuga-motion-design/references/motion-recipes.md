# 动作与特效规格

这里区分固定版本的**源码事实**、浏览器中取得的**运行观察**、直接检查上游图片的**素材观察**、可迁移的**设计推断**和本 skill 的**新增设计**。按钮、速度反馈、进度、逐帧开关的参数用于定位实现。迁移时保留触发、状态、主体和出场之间的关系，根据项目调整量级。运行证据与逐帧覆盖见 [来源索引](sources.md)。

## 主动作确认与真实成功 · Button

**源码事实。**

| 节拍 | 实现与参数关系 |
| --- | --- |
| 预备 | 内部原生 `button` 的 `pointerdown` 把按压弹簧目标设为 `0.5`，增宽系数 `0.24`，增宽发生在压扁过程中。按下加向上楔、两侧颤线、下方短线。离开、释放、取消、失焦让主体目标回 1。键盘原生 `click` 有命中，无这段指针预备。 |
| 命中 | `click` 触发 `impact()`。以主体包围盒中心采样，竖向压到不高于 `0.6`，叠 `1.24` pop 和 `−5°` tilt。短时的深底浅字反相去掉投影。半径 98 px 的爆形在后层，前层有 11 个碎片、分布在外缘的 4 个烟团、上方的 `don` 与侧楔。导语称单帧反相，详细表和实现实际是共享时钟的 190 ms。 |
| 余势 | 约 200 ms 把按压弹簧拨高至 `1.22`，加两侧颤线、下落碎片，烟环在约 200/290/370 ms 依次升起漂向右上。第一段延时检查序号，反相清除和内层烟环没有同一序号守卫。 |
| 稳定 / 业务成功 | 主体回初始变换，效果寿命结束。`done(hold=1.8)` 需业务成功后显式调用，勾在文字尾端弹出、闪点在角部。`hold=0` 留到下一次操作。次按钮的低位为 `0.72`，点击只拨小弹簧并投角部 3 楔。 |

[Button 源码](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/button/button.js#L31-L61) · [文档时序表](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/button/README.md#L45-L62) · [squashy](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/core.js#L217-L226)

**运行观察。** 无头浏览器的 60 Hz 步进中，`click` 后的约 183 ms 仍在反相，约 200 ms 已取消反相。自然时钟上的真实键盘操作能命中，调用成功接口后有勾。两类证据分别说明持续跨度和实际输入通路。

**新增设计。** 将 `press`、`activate` 和 `success/failure` 分开。取消时回复预备原位，保持真实事件、禁用、回车和空格的语义。重放时用本次动作 ID 使旧反相、延时烟和上一次业务响应失效，缩放作用在主体绘制层。比例较低或重击较少的项目，后层只取一爆形，手绘烟和拟声字择一留在视野空处。保存、发布、召出作品时，第一次命中表示已接住操作，真实结果用文本、勾、错误状态或业务页面呈现。

持按形变若用 CSS transition，普通与减少动画模式共用同一个静止属性值。把形变和过渡的适用条件放在普通动效规则内；稳定姿态统一用 `transform: none`，避免媒体查询恢复时从 `none` 过渡到等价的 `translateY(0)`。取消 WAAPI 批次时同时清理派生的按压外观，原生激活仍可完成。

**验收。** 分别取按住、触发后相邻两帧、约 0.2 s、0.37 s、余势消失帧；实点一次成功、一次取消和快速连点，最后用键盘重试。检查表单由业务逻辑决定提交、一次激活一次结果、重放不会继承旧烟或旧完成标志。效果禁用时标签和成败仍然可读。

## 速度反馈与释放 · Slider

**源码事实。** 隐形原生 `range` 掌管输入。`sync()` 将真实值写到数值泡与 `FormData`，归一化值写入 `Spring(0,420,30).to`；主体位置滞后。速度 `v` 是弹簧状态的轨道比例/秒，轨道宽 `W = clientWidth − 28`；因此描画位移为 `x * W`，拖尾门槛 `0.35` 在默认 202 px 的绘制轨宽上约是 71 CSS px/s 的**主体**速度。 `st=1+min(1.5,abs(v)*0.3)`，横宽 `st`、竖高 `1/√st`；原点贴前缘，数值泡倾斜限制在 ±14°。高于阈值时以 `dt*abs(v)*20` 累积发射额，尘、短线、小碎片从反向后缘发射； `abs(v)>1.5` 且冷却 1.1 s 后才可能有 `shu`。 [Slider 帧更新](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/slider/slider.js#L44-L68)

**源码事实。** `change` 检查衰减的有符号速度峰值 `peak`，每帧检测不到更高峰便乘 `0.96`。 `abs(peak)>1.3` 时，斩线、短冲击与碎片沿前进方向发出；约 520 ms 后才出现后侧余烟和颤线。到达 0/100% 另有端点碎片，方向取峰值，零值回退为正。文档用“松手时仍在移动”描述；这个实现实际检测历史峰值，转向或停顿后可能与最后的手势方向和速度不同，衰减也随帧率变动。帧循环没有拖拽开关，键盘和脚本更新通过同一个弹簧也可产生拖尾。 [文档](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/slider/README.md) · [释放和峰值代码](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/slider/slider.js#L46-L68)

**运行观察。** 自然时钟下分别进行分段慢拖与快速短段拖动。慢拖的最大主体速度低于发射阈值，快拖后峰值越过释放阈值，持按约 1.2 s 后衰减至阈值以下。最后用 ArrowLeft 将真实值从 90 改为 89。

**新增设计。** 移植到可拖拽画稿、图形或缩略图时，先定实际拖拽轴、槽位、捕获点和逻辑坐标，把位移沿轴归一化为区间/秒，二维则保留单位方向向量。不动的手指令速度衰减到零。可从两次可信采样算 `vRaw = Δx / Δt`，用 `1−exp(−dt/τ)` 低通取得带方向的 `v`，再钳制异常采样速度。拖动时取弹簧速度产生平滑可读的形变，松手用最近输入速度或有上限的释放窗口判断前抛。保持 `countPerSecond × dt` 的生成额与全层粒子上限，停止拖动、反向、触点取消、捕获丢失、画布离开时停产并清理当前手势；下一次手势从零累计额开始。反向时烟跟在新的后方，中断时不播前抛。槽位按逻辑目标与吸附阈值决定，特效根据落点而不是物理模拟偶然结果触发。

持续手势若同时用 RAF 和 `MediaQueryList.change` 清理，把偏好值初始化到一个局部变量，后续由 `change` 的 `event.matches` 统一更新。输入和帧循环读取此变量，避免在热循环里反复读同一个 MQL 的 `.matches`。在已测 Chromium 中，热循环读到新值时，负责取消墨迹的事件曾未送达该监听器。CSS 可即时隐藏装饰，渲染器仍需取消 RAF、主动清空现有动画和速度。保留合法的指针和手势位置，切换回来以后从下一次有效输入重新采样。

**验收。** 从同距离的慢拖、快拖、快拖后停住再放、反向放、触点取消、键盘步进、点击替代七个输入比较。慢拖时数值跟手而烟量低，快拖伸长且烟留后方，快放的斩线朝前。检查目标命中区不随变形离开输入点，尺寸变动后归一化阈值和边界仍可解释。用两个尺度和一个快速重复序列检验预算。

## 积累与终点 · Progress

**源码事实。** `set(n,instant)` 写 `goal`（0–1）；视觉 `p` 前进时按 `clamp((goal−p)*3,0.12,0.9)` 的比例/秒平滑追近，回退/instant 可直接置位。 `spd` 是 `p` 的滤波速度，前沿从内边到内边按 `p` 插值。地线随 `p*1.25` 展开，云目标大小 `10+25√p`，上方云瓣沿来向按 `spd` 受拖，前沿每越过一个石块阈值便使其弹簧抬升。`p>0.06` 且 `spd>0.02` 时按 `4+60*spd` 速率累计余烟或速度线。`0.3<p<0.9` 首次越线并在视野时有 `gogo`。 [进度与持久层](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/progress/progress.js#L25-L82)

**源码事实。** `p>=1` 设置 `doneAt`，视野中播后层爆形、局部前景爆形、七烟团、掉屑和 `don`；随后云收回、石块落下、单独的已完成勾与地面小烟由 `persist()` 画。 `sakuga:done` 绑定视觉前沿的到达，在同帧标题和 ARIA 数值更新之前发出。页面可见性门限只停画，并仍推进数值。文档的停顿静止可理解为前沿和发射停止；活动云瓣还在正弦滚动，完成态仍有绘制的小云和闪点。若 `gogo` 的 2.9 s 寿命尚未完，完成的 `don` 未检查互斥。 `reset()` 清终点/拟声字门槛，已经入队的短命特效继续。 [完成与重置](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/progress/progress.js#L30-L94) · [文档](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/progress/README.md#L36-L45)

**运行观察。** 以自然时钟调用 `set(1)` 后，最终 `aria-valuenow` 到达 100，测试中收到了恰好一次 `sakuga:done`。

**新增设计。** 任务状态和数值直接以数据源为准，视觉进度是可选的单调追赶层。将“上传到 100%”与“服务端成功”分别建模时，必须等真实成功才显示最终完成。unknown、失败、重试和取消用可读的 DOM 状态，不把持续动画当作错误说明。给每个任务一个身份，本轮完成只发一次。场景离开、重置、失败、隐藏和减少动画使该任务的发射和持久装饰失效；在数据停滞时可让云固定，只保留小而可解释的等待指示；稳定完成后保留文本或静态勾。若短时间跨过积累门限，略过积累拟声。

**验收。** 在 0、起步、越过石块、缓升、急升、停顿、完成和稳定处取帧。实际驱动值跳增、退回、重复到 1、离屏继续、取消后再开始。核对文字与 ARIA 能说明真实状态，百分比清楚，过期任务无完成命中，离开后没有持久绘制。

## 逐帧开关与材质过渡 · Toggle

**源码事实。** 内部原生按钮承载 `role=switch`。触发 `flip()` 先改 `checked`、`aria-checked` 与表单值，再发 `change`，装饰异步走帧。`ON` 为 0…42，以 30 FPS 显示，首帧到末帧间隔约 1.4 s；`OFF` 为 11…0，约 367 ms，播放的是前段倒播。从末帧 42 关时会立即切到较早的拖影帧 11。每个新翻转从预定帧重启。属性直设跳到端点，减少动画当前在 `flip()` 时选端点，帧循环不检查运行中偏好。可见壳体为 108×54 CSS px，绘图框 150×162.5 CSS px，画格 300×325 px，每排 8 格。 [Toggle 源码](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/toggle/toggle.js#L10-L61) · [创作与限制](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/toggle/README.md#L1-L47)

**素材观察。** 直接查看源 WebP 的 43 格。0–3 静止与轻变，4 预备，5–11 拉长拖影，12–13 碰到右端与粉色角标，14–18 水冠上升，19–28 出现画进去的粉色「カチッ!」。29–37 水回落且轨道填色、出现回弹线，38–39 稳定，40–42 闪点长大，最终静态格 42 仍留闪点。壳体小幅位移及 42→11 接缝应按资产和需求评估。原作者记载以 12 张关键姿态为参照分批生成并对准外壳。归档的是 43 格成品，原始关键帧与中间制作物不在固定版本的源码树。 [源图集](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/toggle/frames.webp)

**运行观察。** 60 Hz 浏览器取帧复核了 42→11 的跳接及随后倒回 0；实际单击打开、空格关闭时，`aria-checked` 先更新，分别停在画格 42 和 0。

**新增设计。** 有高辨识度的破边、水冠、布料或轮廓变形时，可以采用逐帧图集。先绘制中性端点、预备、最大拖影、接触、余势、稳定姿态。用不可移动的参考线注册主体围框与锚点，按动作两向规划相容的帧路线。首尾建静态样式，给解码失败、预载完成前和降动效准备清楚的 `checked` 静态 DOM 或等价绘图。快速反转通过当前姿态找最近的合法桥接点，代价过高时直接切到清楚的静态终态。画格透明边保留所有喷溅，资源替换与主题路线见 [项目风格配置](profiles.md)。

**验收。** 查首尾帧、最大扩张、42→11 接缝、双向快速反转、脚本直设、解码失败和动画途中启用减少动画。逐帧比较壳体轮廓对位和画格边界，实点及键盘用法核对 `aria-checked` 与提交值同拍。静态主题应在视觉上保有不同的开关状态。

## 通用中断契约

**新增设计。** 每个动作明确它拥有的动画、指针、发射器、延时和效果层。新操作可以替换同对象的动画，也可以保留无冲突的短尾。场景销毁应释放全部所有权。共享时钟可以提供已知时点，但上游 `later()` 没有取消句柄，`Base` 断开只移除自身帧回调。新组件可以采用可取消任务或任务 ID。 `calm` 在上游主要阻止 `add()` 入队，既有绘制、组件弹簧和 CSS 过渡不自动跳到终态。衍生设计应在偏好变更时重设视觉目标为当前真实状态、清空已运行的装饰并停止发射。 [共享层、reduce 与时钟](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/core.js#L28-L83) · [Base 生命周期](https://github.com/finktheartist/sakuga-vfx/blob/c3dabb173928a3ad2372183103caf2e6f50953d0/core.js#L232-L246)
