# 个性化配置与素材

**新增设计。** 用一份项目配置定义 DOM、运动和效果层。先为项目选节奏和面积预算，再调颜色。保持「主体传达方向与状态、命中有主次、静止可读、效果能自行收束」。轮廓、明暗和形变服务于物性。若因项目目标改用透明度、轻质无描边或持续装饰，应记录目的（如图像需要让位给阅读）及对轮廓辨识、视觉负担或效果预算的影响。

## 配置契约

[示例代码](../assets/web/profiles.js) 是一份可运行的 JavaScript 配置。移植时可保留语义字段，按渲染器适配具体单位。

| 配置 | 含义与关系 | 示例落点 |
| --- | --- | --- |
| `colors` | 纸、主墨、主体亮面、平涂阴影、强调色、背景板和规则线。墨线需要同时区分亮面和阴影；强调色只为焦点和命中服务 | `applyCssProfile` 写场景 CSS 属性，Canvas 同时从该对象取色 |
| `shape` | DOM 描边、圆角、FX 描边。细线在高密度时尤其要限制；描边和小粒子需一起检查 | `stroke/corner/effectStroke`，CSS 与 Canvas 分别使用 |
| `press` | 持有/命中缩放、过冲、对比拍长、恢复长。压得更低时侧向补偿，保留可读宽度；对比拍必须落在恢复之前 | 稳定命中面内的表现层 |
| `drag` | 刚度、阻尼、形变量、尾迹门槛、满速、释放门槛和发射频率。速度用轨道长度/秒，阈值在 0 与满速之间；高刚度配适当阻尼，免得拖尾喧宾夺主 | 位置弹簧、方向形变、粒子沿速度反向发出 |
| `reveal` | 标题位移、图板位移、过冲、全段毫秒数。图板承担更大的位移，标题仍可读；窄屏检查文字与画布边界 | 章节标题与装饰图板的独立姿态 |
| `effects` | 范围、密度、时长、额度、拟声策略。稳态粒子数粗估为发射率 × 寿命 × 每次粒子数，再给命中留额度。范围同时乘对象及场景安全区约束，轮廓宽度别随寿命放大 | 三层共享额度，按动作优先级淘汰；拟声是独立装饰 |

## 两种示例预设

| 同一场景 | 克制 `restrained` | 表现 `expressive` |
| --- | --- | --- |
| 轮廓 | 2px、4px 圆角、FX 1.45px | 3px、2px 圆角、FX 1.85px |
| 压击 | 持有缩放 0.86、恢复 290ms | 持有缩放 0.63、恢复 440ms |
| 拖动 | 拉伸额度 0.14、6 次/秒 | 拉伸额度 0.36、14 次/秒 |
| 章节位移 | 标题/图板 12/19 CSS px、346ms | 23/43 CSS px、500ms |
| 效果额度 | 总额 12、范围系数 0.72、拟声关 | 总额 28、范围系数 1、允许压击时绘制矢量拟声 |

克制版适合连续浏览与常用操作，表现版适合作品页主动触发的场景换拍。每次改变预设先按新规则结束旧视觉批次；已有业务状态与焦点继续由应用管理。改变减少动画偏好时单独撤销运动与效果。预设内的数值是这套 Web 样例的工作值，按宿主尺寸和语境复验。

同一动作的两档共用动作原因与接触关系。可以分别设总时长与命中比例，并用同一 `hitMs = duration * hitPhase` 驱动该档的压缩、接触痕迹与冲击绘制。比较各档接触前、接触与稳定的同一相位，额外用同一毫秒取样说明等待和余势的差异。

## 四类实现来源

| 来源 | 可直接或实时调整 | 需要进一步工作 |
| --- | --- | --- |
| 原生控件 CSS | 以 `--sk-ink/card/pri/acc/soft/bw/r/...` 覆盖根或被测宿主。检查当前组件实际引用的 token，`--sk-sh` 等可能间接引用其他 token | Toggle 的画稿主体、Canvas 特效和直接写死的值不会自动随 CSS 更新 |
| Canvas 调色盘与绘制参数 | 上游 `SakugaFX.P` 是全局对象；建议项目自己的适配层显式传入色值、描边、范围、方向、寿命与预算 | 上游效果有的读绘制时的 `P`，有的在创建时捕获颜色，或已烘焙为 Canvas。如用 `hollow()/dotted()` 检查其单独的色值。主题热切换采用重建或清场，测试两个主题分别新触发和切换前后 |
| 预制矢量拟声 | 现有轮廓的填充、描边、点纹、位置、大小、角度可调；上游 `sfx()` 使用已登记的词键 | 字形本体、中文或品牌字需要新轮廓/明确可用字体，不能传任意字符串给上游的六个词键 |
| 绘制帧序列 | 播放时机、静态首末帧、帧索引路线、观看尺寸可调 | 物体形状、固定色、液体或画入字样需重绘、做遮罩/分层或提供变体图集 |

## 增加中文拟声与新帧

- **中文拟声字。** 先定动作和词义（如「啪」用于短触，「咚」用于重落），一次命中最多一组；先验证无字仍明确。用项目原创画稿或有相应许可的字形，输出 SVG 路径（明确 viewBox、内孔填充规则和描边）或透明位图。也可参考上游 `art/words/` → `tools/trace.py` → `core.js` 中的路径管线。拆开字面、轮廓和点纹，按色方案以及 DPR 验证小尺寸和中文读形，字号/脚本保留原状态文字，装饰层隐藏于无障碍树。若使用缓存，键包含词、色彩和纹理；检查版本切换与缓存上界。沉默、开关、语言和小屏回退属于配置。
- **新手绘帧。** 先定取样节奏和静止首尾。用固定画布的姿态表标出压缩、拖影、撞点、余浪、静止，画稿逐帧对齐铰点或主体外框。单独画逆向过渡或约定从当前可见姿态换向；制作透明 atlas 并写入每格尺寸、列数、计数与 fps。验证每格像素、最后一格和透明边界，预解码后播放，失败时显示能表达状态的静态替代。实际验证快速来回、系统偏好变化、首用冷加载及尺寸放大。图集包含字样时需要无字变体或可独立裁切的字层。
