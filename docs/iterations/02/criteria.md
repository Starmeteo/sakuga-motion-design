# 迭代 02 固定验收

基线为 `55bd33ba3a6659ce32c0e2542dd113a5129eea15`。开发题在运行旧版前冻结。独立代理只看指定版本的 skill、该题和必要工具；从空目录开始。评估运行产物，生成差异包含执行者变异。这里没有推断模型总体成功率。

## 共通口径

| 编号 | 通过条件 |
| --- | --- |
| R | 真实输出可启动、无脚本错误，无运行依赖或整站支架，保留原生语义或等价可读状态。 |
| I | 1360×920 的 Chromium 实际指针、键盘和 390×844 DPR 2 的仿真触摸正常操作。窄视口无横滚或裁掉操作。 |
| M | 从初载即减少动画、从活跃动作动态进入两种条件测试。状态保持或照常提交，主体到达稳定姿态，临时装饰消失；恢复后只为新动作启动。 |
| V | 主体与锚点清楚，色块和有意的轮廓，命中前后明确，文字和焦点可读，静止无装饰循环。必须检查实际画面，只有静态图不判定动作时序。 |
| U | 记录是否选择适用 skill 以及实际读过的入口/参考/资源。非适用题保持局部文本修改。catalog 匹配属于独立执行者判断，和客户端自动分发日志区分。 |

## 输入与任务专用断言

| 题目 | 正常速度输入和机器/人工断言 | 时间或画面判断 |
| --- | --- | --- |
| 01 标记 | 初始待校，点击已校，Enter 回待校，Space 已校，移出松手保持已校。再在待校时按住且切换系统减少动画，松手仍只提交一次。连续 3 次激活后状态按奇偶。触摸一次提交。 | 未提交之前只有蓄势，标记强、撤销弱，持按、释放后约 65 ms 和 500 ms 都可读；临时主效只在激活之后。 |
| 02 拖画稿 | 起于中位，实际慢拖向上，快速等量拖向下，另验证反向、静止 350 ms 再放、Escape、CDP touchCancel、键盘和按钮替代。浏览器鼠标释放后择近托位；取消保持承诺值。 | 快拖比慢拖伸长更明显，墨迹在来路，放前静止无高速释放。窄屏边界不吞掉主体。动效关闭后可即时定位，所读状态与提交入口一致。 |
| 03 章节 | 按钮逐个切换，Enter 和触摸可提交。以 30–80 ms 间隙切 走墨→收版→纸面，最新章节的标题、说明和选中指示一致；无旧效果再次出现。 | 正向/反向可区分，动效接触区明确，文字在首个可见帧保持可读和位于版面内，500–900 ms 安静。 |
| 04 双预设 | 12 次累计中切换两档，换档只改表现，印次保留，切换按钮上的焦点不被脚本挪走，下一次落版用新档。键鼠和触摸各验证至少一次落版。 | 比较同一个落版动作，除颜色外至少两项机械差异，如幅度、时长、效果形状或密度。相同的业务状态；换档后旧姿态与粒子立即终止，两档均回静止。 |
| 05 控制题 | 返回精确的一行 HTML，保持结构和其他文字。 | 不应加载动效参考、依赖或创建页面。 |

稳定用例以最后状态为准。图样按静止、动作初期、中段与稳定取样，支持固定时钟则记录毫秒偏移，实时截图只记录采集窗口。已有 [整合示例回归](../../../tools/verify-demo.mjs) 与 [旧迁移回归](../../evidence/forward/verify.mjs) 继续运行。Chromium 仿真与无头指标不等同于物理设备性能。
