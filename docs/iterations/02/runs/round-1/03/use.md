# 章节卡实现记录

阅读了候选技能的 `SKILL.md` 和 `references/visual-language.md`、`motion-recipes.md`、`scenes.md`、`verification.md`。另阅读了 `profiles.md` 的揭示参数，章节卡使用单档动作。

点击时同步提交章节名称、说明、图板和选中态。三幅 Canvas 图板为原创绘制。新图板按章节序号差从对应侧伸展进场，越过对齐线再回稳。标题和说明始终静止。两道短墨线只出现在图板区域。新切换、窗口变动和减少动画设置会撤销整批动画。

在本地 Chromium 用鼠标、Tab、Enter、Space 及协议触摸测试。分别在 1120 px 和 390 px 检查布局，390 px 无横向溢出。首段第 6 ms 的图板水平偏移在桌面为 +41 和 −41 px。快速切换后只留最后一章。测试了减少动画在加载时开启、中途开启以及重新关闭。真机触屏与屏幕阅读器未测。
