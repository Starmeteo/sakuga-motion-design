# 落版实现记录

阅读了候选技能的 `SKILL.md` 和 `references/visual-language.md`、`motion-recipes.md`、`scenes.md`、`profiles.md`、`verification.md`。

原生按钮即时提交印次。原创 CSS 印板先抬起，再下压并回弹。一份 `profiles` 配置控制调色、描边、时长、抬升、压缩、回弹和接触楔。克制与表现档的时长为 318 和 465 ms，接触时纵向缩放为 0.88 和 0.74，接触楔为 2 和 6 个。每档共用一个接触时点驱动压缩、出印和飞楔。改档或偏好变化会结束本批动作，保留印次和当前 DOM 焦点。

本地 Chromium 检查了鼠标、Tab、方向键、Enter、Space 及协议触摸。在 390 px 检查无横向溢出。定点检查 60 ms 时未出印或飞楔，105 ms 和 170 ms 分别观察到两档的下压、印痕及飞楔。检查了连点、动作中改档、下一次按新档触发、普通收尾以及加载前和动作中启用减少动画。真机触屏与屏幕阅读器未测。
