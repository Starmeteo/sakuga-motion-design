# 基线 03 章节卡

Chromium 浏览器机器断言 14/14。快速点「走墨 → 收版 → 纸面」的真实点击间隔为 65.8 和 62.8 ms。末次点击后逐帧记录的标题、说明和 `aria-pressed` 都是「纸面」的数据。较早场景动画实例没有复现，点击后 500–900 ms 的采样没有活跃动画。另在 390×844、DPR 2 仿真触摸提交「收版」，页面宽 390 CSS px。键盘以 Tab 到达「走墨」，按 Enter 成功提交。

- 首帧方向可辨。图板初始偏移分别为 +54 px 和 −54 px，倾斜和边缘短线随方向镜像；角色图块都留在固定外框里可识别。图板在 65 ms 回到距稳态约 1.4 px，500 ms 无短线。 [方向图板取样](direction-review.png)
- 标题及说明不随图板形变，字号、对比和位置在切换首帧保持可读；桌面键盘焦点有独立橙线。窄页将内容和图板纵向排布，三个按钮都完整露出。 [布局与焦点取样](layout-review.png)
- 动态开启减少动画时，正在运行的图板与短线动画均撤销，章节保留「收版」。恢复设置后静止，下一次点击才重新开始。预先减少动画时直接提交并画出新图板。 [动态减少动画](chapter-reduced-midflight.png)
