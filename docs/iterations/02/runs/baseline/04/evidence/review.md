# 基线 04 双预设

Chromium 浏览器机器断言 12/12。连续十二次落版的计数由 0 增到 12，含一次 Tab 后 Enter 提交；在第 3、6、9 次动作尚活跃时换档，计数分别仍为 3、6、9，焦点留在点下的换档钮。换档后首个读值中印板变换为 `none`，活跃动画实例为 0，四个粒子的透明度归零。390×844、DPR 2 手机仿真以触摸换档和落版均成功，无横滚。

- 两档接触姿态明显不同。印板动画 313 / 462 ms，固定 65 ms 时印板上提约 28 / 64 px，接触缩放约 1.073×0.865 / 1.216×0.652，接触楔片为 2 / 4 个。两档 500–900 ms 都静止。预设集中在 [基线单页](../index.html) 244–267 行。 [两档画面对照](impact-review.png)
- 固定验收 V 的命中时序未通过。初始纸张无彩色印样，第一次点击后，固定 65 ms 的画面里两档印板仍提在纸样上方，但纸面已经有彩色斜纹印样。区别于阴影和既有定位线的是新增的斜纹图案。克制档到 120 ms 才到达接触姿态并出现楔片，表现档到 175 ms 才出现这些视觉落点。业务印次立即增加符合约定。 [固定接触帧](impact-review.png)
- [基线单页](../index.html) 339–345 行同步增加印次并设置 `impression.hidden = false`，随后才开启动画。299–335 行定义真正的命中在每档时间轴的 37.5%。因此预备、落板和粒子时序虽然可辨，纸面反馈早于接触。 [初始无印样](profile-initial.png)
- 动态开启减少动画时，活跃姿态与粒子取消，已累计一次印次保留。恢复减少动画设置后无动画，下一次点击正常计数和播放。初载减少动画亦直接提交并显示稳定印样。 [动态减少动画](profile-reduced-midflight.png)
