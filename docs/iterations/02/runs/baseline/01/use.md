# 标记校样

直接打开同目录的 `index.html`。入口为原生按钮「标记校样」。

读取基线技能的 `SKILL.md`、`references/visual-language.md`、`references/motion-recipes.md` 的 Button 和中断规格、`references/profiles.md`、`references/verification.md`。采用原创 CSS/JS 实现。按钮的稳定命中区域与压缩面分离，原生 click 统一提交状态。成功帧用章面压缩和六笔边缘墨迹，撤销只收一下章面。新操作和减少动画偏好会取消前次效果。

Chromium 在 390 px 下通过 Tab/Enter/Space、鼠标持按移出释放、命中、快速重复、运动中切换减少动画，以及启动时减少动画下的模拟触摸点按。另目视检查持按和命中约 41 ms 画面。未测实体触屏和读屏。
