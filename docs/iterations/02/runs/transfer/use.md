# 闭馆巡检工单重排

浏览器打开 [index.html](index.html) 即可操作。每条工单仍使用原生按钮。点选任意一条更新唯一的优先项，再次激活同一条取消优先并按编号归位。

## 使用过的材料

- 输入为 [封存任务](request.md) 和 [初始页面](starter.html)。
- 从 `.iteration-work/candidate-3/sakuga-motion-design/` 读取 `SKILL.md`、`references/visual-language.md`、`references/motion-recipes.md`、`references/scenes.md` 和 `references/verification.md`。
- 采用衍生创作路径。用技能的前沿锚点、背景独立变形、同一批次取消和逐帧取样规则，设计这个列表的局部重排。运行验证使用本机已有的 Playwright 与 Chromium。

## 动作与状态

按钮激活时先采样各行当前的位置，再在同一次事件中提交 DOM 排序、唯一选中状态和状态提示。移位后保留原按钮焦点，各行从采样位置过渡到已提交的位置。若新操作赶在上一轮中途发生，先采样当时正在显示的位置，再取消旧轮并播放新轮。

主工单先朝行进反方向回蓄最多 4 CSS px，再沿排序轴加速。卡片底板沿前缘支点拉长，几个经过的行分先后挪位。经过时主工单底板内收，形成独立编号通道，前景工单旁留一小道淡出的来向笔触。触达目标边后，底板再次压缩并归正。标题、位置文本、编号和按钮保持原字形，主工单掠过时会短暂遮住经过行的部分内容，编号从左侧通道露出。已在正确位置的 101 改变优先状态时只更新静态状态。

动作在 `animateReorder()` 调整。总时长由移动距离决定，上限 332 ms。主工单在 77% 左右抵达，随后完成底板回弹。列表自身裁切效果。偏好切换、窗口改变尺寸或页面隐藏时取消当前批次，页面直接显示已提交的顺序。

## 起势、经过、落稳

Chromium 159.0.8154.6，670×540 CSS px，DPR 1，截取整个页面。上移用鼠标点击 105；归位先用鼠标将 105 调至队首，正常播放结束后对原按钮按空格。取样时暂停当前批次，设置每个 WAAPI 动作的 `currentTime`，末帧完成批次后再截图。

| 操作 | 起势 · 42 ms | 经过 · 137 ms | 落稳 · 332 ms 后 |
| --- | --- | --- | --- |
| 105 去队首 | [上移起势](up-01-start.png) | [向上掠过](up-02-pass.png) | [队首落稳](up-03-rest.png) |
| 105 按编号归位 | [回程起势](down-01-start.png) | [向下掠过](down-02-pass.png) | [归位落稳](down-03-rest.png) |

双向实测到了 42 ms 时纵向压缩至 0.94 倍，137 ms 时沿纵向拉伸至 1.089 倍、编号到主底板还有约 8 CSS px 间隙、经过行已挪位。262 ms 时主行已到目标位置、底板仍带约 0.95 倍落点压缩，笔触已收。检查了六张截图，归位的键盘焦点环随原按钮留在 105。

## 正常速度验证

通过 Playwright 的鼠标、键盘和触摸入口分别操作，在浏览器自然时钟下检查实际页面。随后使用归档的 [独立验收脚本](../../check-transfer.mjs) 复查正式题面的 900 px 与 360 px 条件。

| 操作 | 观察结果 |
| --- | --- |
| 鼠标点 105，按空格归位，Shift+Tab 后按 Enter 激活和取消 104 | DOM 顺序、状态提示和 `aria-pressed` 在点击事件返回前同步。焦点保留在对应原按钮。 |
| 在 101 已处于队首时连续按按钮两次 | 状态从普通顺序到 101 优先、再回普通顺序。位置无变化，未启动位移动画。 |
| 105 正在上移时用 Tab 两次改到 102，按 Enter 切换优先后再次按 Enter | 三次激活各提交一次，最终按 101 至 105 排列、焦点在 102，动画与临时标记全部清理。 |
| 手机模拟 320 与 390 CSS px、DPR 2，触摸 104，动作途中改变视口宽度，再触摸取消 | 按钮触摸高度至少 44 CSS px。两种宽度均无横向滚动，尺寸改变时动作立即结束，仍可继续操作。 |
| 加载前减少动效、播放中减少动效、恢复普通偏好 | 静态模式即时排序。中途切换清空批次，恢复后静止，下一次操作才重启动作。 |

正常速度和取帧均通过 Chromium 无头模式执行，运行期间未捕获页面错误。手机触摸来自协议模拟，实机触屏和屏幕阅读器输出待校验。
