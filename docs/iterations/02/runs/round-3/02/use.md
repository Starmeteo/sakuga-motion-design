# 画稿托位开发记录

阅读了候选包的 `SKILL.md`、`references/visual-language.md`、`references/motion-recipes.md` 的速度反馈与中断段、`references/scenes.md` 和 `references/verification.md`。

- **原生交互。** 用指针捕获保持拖拽，按抓取点直接更新竖向预览。相邻托位的预览切换带 6 px 滞回。松手、点选和方向键共用状态提交，按钮选中态、画稿位置和读屏状态文字同步更新。Escape、触点取消、捕获丢失和失焦清空预览并回到已提交位置。
- **原创动效。** CSS 画稿的绘制层随轨道归一化速度伸缩，以前缘为支点。Canvas 每批最多绘制 12 道墨痕，沿竖向来路收短。高速落点只使用最近 94 ms 的有效移动速度。偏好改为减少动画时立即清理描画，保留手势和预览位置。
- **已验证。** 在无头 Chromium 直接打开文件。880 px 下用鼠标测了同距离快慢拖、双向尾迹、停住后释放、Escape、高速落点和随后点选，也测了聚焦画稿重复按方向键。390 px、DPR 2 下通过 CDP 模拟触摸取消、点选和拖动中切换减少动画，核对清屏、恢复后无旧动画及继续松手提交。检查了静止、快拖和窄屏截图。实物触屏和读屏播报未测试。
